Tina CMS Admin

To open the visual editor:

  1. In Tina Cloud, add your Git branch (e.g. main) and ensure the repo is connected: app.tina.io → your project → Configuration → add branch / Site URLs.
  2. From frontend run: npm run build:admin (uses .env – Tins_client and Tina_token are read as clientId and token).
  3. Refresh this page; the real Tina admin will load here.

You can also edit content/global/index.json and content/home/home.json directly in the repo.
