# Render Deployment Guide

## Quick Start

1. **Connect your GitHub repository to Render**
   - Go to [Render Dashboard](https://dashboard.render.com)
   - Click "New +" → "Web Service"
   - Connect your GitHub repository
   - Select the `youtubeadwords` repository

2. **Render will auto-detect `render.yaml`**
   - The service will be configured automatically
   - All environment variables will be set up

3. **Set Required Environment Variables**
   Go to your service → Environment and set:
   
   **Required:**
   - `DATABASE_URL` - Your PostgreSQL connection string (Neon or Render PostgreSQL)
   - `FRONTEND_URL` - Your frontend URL (e.g., `https://your-frontend.onrender.com`)
   - `API_URL` - Your backend URL (will be `https://youtubeadwords-backend.onrender.com` after deployment)
   
   **Optional (for payments):**
   - `UPLEF_API_KEY` - Uplef payment API key
   - `UPLEF_API_SECRET` - Uplef payment API secret
   - `WEBHOOK_SECRET` - Uplef webhook secret
   
   **Optional (for YouTube search):**
   - `YOUTUBE_API_KEY` - YouTube Data API key
   
   **Auto-generated:**
   - `SESSION_SECRET` - Will be auto-generated by Render if not set
   - `PORT` - Automatically set to 10000 on Render
   - `NODE_ENV` - Automatically set to `production`

4. **Database Setup**
   - After first deployment, run migrations:
   ```bash
   # Via Render Shell or locally:
   cd backend && npx prisma migrate deploy
   ```
   Or use Render's shell to run:
   ```bash
   cd backend && npx prisma db push
   ```

5. **Deploy**
   - Render will automatically deploy on every push to main branch
   - Or manually trigger deployment from the dashboard

## Environment Variables Reference

See `backend/.env.example` for all available environment variables.

## Health Check

The service includes a health check endpoint at `/api/health` which Render uses to verify the service is running.

## Notes

- The backend listens on `0.0.0.0` to accept connections from Render's load balancer
- Port is automatically set by Render (default: 10000)
- CORS is configured to allow your frontend URL
- Cookies are set to `secure: true` in production (HTTPS only)
